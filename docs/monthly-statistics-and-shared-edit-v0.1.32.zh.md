# v0.1.32 月份统计与双设备共享编辑

## 本次需求

Jeff 可以按月份查询登记数量，并在两台电脑上同时使用同一个云端订单工具。

## 使用方式

1. 两台电脑都打开同一个 OCI 云端网址并登录，不要分别启动两份独立本地数据库。
2. 首页点击“月份统计”，选择登记月份后点击“查询”。页面会显示订单笔数、登记数量总计、待核销、已先交、返厂、已核销和该月订单明细。
3. 两台电脑可以同时登记不同订单、修改不同订单和核销订单。
4. 如果两台电脑同时打开同一订单，另一台先保存后，旧页面再次保存会被拒绝并提示刷新。这是保护措施，避免后保存覆盖刚更新的正常订单。

## 云端切换

云端环境必须使用：

```text
JEFF_DEPLOYMENT_MODE=cloud
JEFF_CLOUD_SYNC_READ_ONLY=false
```

切换前先备份云端 SQLite 数据库，确认 `/api/health` 正常，再重建固定版本镜像。两台设备都以云端为共同主库；离线版同步仍用于迁移和备份，不作为两份独立主库长期并行录入。

## 验证顺序

先运行类型检查和 lint，再运行月份统计及现有订单回归测试；部署后检查健康接口、登录、两台设备分别登记一笔订单、刷新后能互相看到，并构造同一订单过期保存场景确认页面会拒绝覆盖。
